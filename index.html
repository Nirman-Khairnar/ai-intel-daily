UPDATE Claude Code — Dynamic Workflows

Anthropic launched Dynamic Workflows in Claude Code (June 2). Claude now writes its own multi-agent harness on the fly — up to 1,000 agents per run. Six core patterns: Classify & Act, Fan Out & Synthesize, Adversarial Verification, Generate & Filter, Tournament, Loop Until Done. This is the orchestration layer that makes agentic AI actually usable for complex business tasks.

UPDATE GitHub Copilot — Usage-Based Billing Live

As of June 1, 2026, GitHub Copilot moved from Premium Request Units to usage-based billing via GitHub AI Credits. Agent mode, code review, and long-running tasks now consume credits. Repository-level AGENTS.md support added. Code review also consumes Actions minutes. This signals AI coding assistants becoming metered cloud infrastructure, not flat-rate tools.

RISK US AI Regulation — State Laws Creating Compliance Patchwork

No federal AI law, but state legislatures are filling the void. Colorado's SB 24-205 targets "high-risk" AI systems in hiring, housing, healthcare. NYC Local Law 144 covers automated employment decisions. Illinois, Maryland, New Jersey have hiring restrictions. The compliance picture is getting complicated fast for any business using AI in consequential decisions.

RISK GitHub Copilot Pricing Shift — Token-Based Metering Is the New Normal

The shift from flat-rate to usage-based billing across AI providers (GitHub Copilot, Claude, OpenAI Codex) means costs can spike unpredictably. Agent mode and long-running workflows consume credits fast. Budget controls and governance policies are now essential, not optional. For SMBs, this makes self-hosted/open-source alternatives (like Hermes Agent) more attractive.
